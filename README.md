# Notification Platform

ДЗ4 по сервис-ориентированным архитектурам. Проект централизованной платформы уведомлений онлайн-банка с доставкой по push, SMS и email.

- [Требования к платформе](requirements.md) — функциональные и нефункциональные требования, ASR, архитектурные вопросы и неопределённости.
- [RFC по доставке критичных уведомлений](rfc.md) — два варианта архитектуры, расчёт нагрузки и выбор механизма переключения на резервные каналы.
- [Диаграммы](diagrams/) — по одной C4 Container и две sequence-диаграммы на вариант. Рядом с исходниками PlantUML лежат готовые SVG.
